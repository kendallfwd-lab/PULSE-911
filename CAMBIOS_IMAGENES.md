Los datos ya guardados en el navegador actualizan solo las rutas de imagen de estos registros de demostración y respetan las fotos adjuntadas por los usuarios.

Para ejecutar: `npm install` y `npm run dev`. Para compilar: `npm run build`. La carpeta `dist` incluida corresponde a esta versión.
