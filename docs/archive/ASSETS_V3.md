# PULSE 911 V3 — mapa de imágenes

## Emergencias / publicaciones
- `accidente-vehicular.webp`: feed ciudadano, detalle del incidente y Command.
- `incendio-estructural.webp`: feed ciudadano y reportes de incendio.
- `inundacion.webp`: publicaciones de calle inundada y mapas de riesgo.
- `riesgo-vial.webp`: publicación de punto peligroso y zonas de riesgo.

## Cursos y ayuda personal
- `primeros-auxilios-preparacion.webp`: preparación y primeros pasos después de un incidente.
- `plan-familiar.webp`: plan familiar y comunicación ante emergencias.
- `rcp-basico.webp`: curso introductorio de RCP.
- `apoyo-psicologico.webp`: apoyo emocional y recuperación posterior a accidentes.

## Administración / PULSE Command
- `despacho-unidad-cercana.webp`: referencia visual del flujo para comparar ETA, distancia y capacidad.
- `zonas-riesgo-analitica.webp`: referencia visual de mapas de calor, intersecciones peligrosas y tendencias.

## Sistema
- `civic-feed-reference.webp`: portada / experiencia Citizen.
- `situational-hybrid.webp`: mapa operativo híbrido.
- `satellite-city.webp`: modo satelital.
- `public-preview.jpg`: vista pública.
- `report-preview.jpg`: flujo de reporte.
- `tracking-preview.jpg`: seguimiento ciudadano.
- `profile-preview.jpg`: ficha de emergencia.
- `command-preview.jpg`: vista de PULSE Command.
- `command-center.jpg`: centro de coordinación representativo.
- `wellbeing-preview.jpg`: apoyo y recuperación.
