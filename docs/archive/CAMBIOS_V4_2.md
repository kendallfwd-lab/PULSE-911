# PULSE 911 — V4.2 · Corrección de Inicio / Presentación

Esta revisión corrige específicamente la página pública de Inicio/Presentación para escritorio y laptop.

## Correcciones principales

- El navbar público ya no queda separado del borde superior al hacer scroll.
- Se corrigió el `top` sticky que estaba desfasado respecto a la franja de simulación.
- Header público reducido a 52–56 px en desktop/laptop.
- Navegación y botones compactados para 1366×768, 1440×900, 1600×900 y 1920×1080.
- El hero inicial reduce su altura y aprovecha mejor el ancho disponible.
- La vista previa principal ya no usa perspectiva que pudiera provocar recortes visuales.
- Imagen principal de presentación reducida para que el bloque inicial quepa mejor a 100% de zoom.
- Secciones públicas con menos espacio vertical y mayor ancho útil.
- Las cuatro vistas del producto aparecen en una sola fila en monitores amplios.
- Se compactaron mapa de presentación, centro de operaciones, cursos, bloque de seguridad y footer.
- Se preservó el responsive para tablet y móvil.

## Resoluciones objetivo

- 1366×768
- 1440×900
- 1600×900
- 1920×1080 o superior

La interfaz debe utilizarse a 100% de zoom del navegador.
